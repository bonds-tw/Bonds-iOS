# MyData 下載後的失敗重試

延續 PR #69 的 MyData 相容流程，這次只修正下載後兩個無法順利接續的地方。

## 簽章失敗

原先資料已解析、簽章失敗時，畫面只有錯誤提示和「完成」，使用者只能離開後重新取得資料。
現在失敗畫面提供「重試簽章」，使用這次畫面記憶體中的同一份資料，重新走既有簽章操作。

- 原有自動開始簽章的時機不變，不增加確認步驟。
- 進行中顯示「簽章中」，擋住重複請求；只有簽章及儲存成功才顯示「完成」。
- 可以按「關閉」離開。已開始的工作仍照原本方式獨立完成並儲存，不依賴畫面存在。
- 重試資料不另存檔；成功或按關閉後移除重試用的參照。
- 過期的錯誤提示不會在下一次重試途中跳出。
- 既有簽章操作只抽成可注入函式，TW FidO 請求、簽章驗證、暫時金鑰清理、卡片 id 與儲存方式照舊。

## PDF 密碼錯誤

原先輸入錯誤會立即再彈出一個沒有取消選項的提示。現在會等前一個提示關閉，
再提供新的輸入提示，使用記憶體中的同一份 PDF，不必重新下載。

- 提供取消；取消後留在原本的 MyData 頁面，明確說明尚未匯入，準備好可重新下載。
- 輸入採遮蔽顯示，使用英數鍵盤、關閉自動更正，空白輸入不能送出。
- 先用原樣輸入解密，保留既有密碼相容性；失敗才嘗試移除前後空白、轉大寫。
- 提交或取消會清空輸入欄。提示、控制器之間保留弱參照，避免輸入資料因循環參照留存。
- 暫存 ZIP/PDF 的清除時機不變；取消不保存解密密碼或原檔。

## 驗證與界線

單元測試控制簽章結果，檢查失敗後重試、連點防護、成功後不可再送出、
關閉後原本工作繼續、關閉後不可使用先前資料重試，以及密碼提示的取消、輸入和釋放。
模擬器 UI 測試操作簽章失敗後重試，以及加密 PDF 的錯誤密碼、正確密碼與取消。
UI fixture 僅編入 DEBUG，使用非真人資料，不連接簽章服務、不建立真實憑證。

這些測試不代表已完成真人的 MyData 驗證與 TW FidO 簽章。仍需在真機確認
官方登入、App 切換、文件下載和實際領卡；本次不新增後端、不改簽章系統，
也不增加介接申請或測試用途標示。
